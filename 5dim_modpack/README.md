# 5Dim's Mod - Modpack

Enable the complete 5Dim suite in a single install.

5Dim Modpack is a metapackage that pulls in every 5Dim module, utility package and development helper at once, so you can run the full collection without adding each mod by hand.

## What This Mod Adds

- A single dependency package that installs the whole 5Dim suite.
- All core, content, utility and development modules in one step.
- A simple way to keep the full collection enabled and in sync.

## Good Fit If You Want

- The entire 5Dim experience without managing each module individually.
- A quick, all-in-one setup for a full 5Dim playthrough.

## Requirements

- Requires the Space Age and Quality DLC mods, because the pack includes 5dim_space_age.
- Requires Bob's Inserters, because the pack includes 5dim_transport.
- Pulls in every 5Dim module as a dependency.

## Notes

- This module contains no content of its own; it only declares dependencies.
- Install individual 5Dim modules instead if you prefer a smaller, hand-picked mod list.

Part of the 5Dim mod collection for Factorio.
