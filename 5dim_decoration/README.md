# 5Dim's Mod - Decoration

Give your factory clearer labels, markers and visual identity.

5Dim Decoration adds placeable numbers, letters and decorative markers so you can organize stations, production blocks and factory districts more clearly.

## What This Mod Adds

- Placeable numbers from 0 to 9.
- Placeable letters from A to Z.
- Decorative tiles and visual markers.
- More tools for labeling zones, train areas and factory blocks.

## Good Fit If You Want

- Cleaner visual organization.
- Better labels for depots, stations and production districts.
- A more personalized factory without changing core gameplay.

## Requirements

- Requires 5dim_core.

## Notes

- A cosmetic support module with practical use for large organized bases.
- Great for players who like readable layouts and visual planning.

Part of the 5Dim mod collection for Factorio.
