# Mapa De Familias Upgrade

Este documento lista las familias de recipes que se tratan como upgrade de otra familia base.

## Regla

- MK1 recipes place the upgraded base item first, followed by the non-upgrade delta ingredients.
- MK2+ recipes place the previous upgrade tier first, the same-MK base-family item second, and the delta ingredients after that.
- The base-family ingredient stays at amount 1.
- Hybrid families can keep their vanilla base recipe intact and start the upgrade mapping at MK2.
