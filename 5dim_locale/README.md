# 5Dim's Mod - Locales

Play the 5Dim suite in your language.

5Dim Locales adds translation support across the 5Dim collection, making items, technologies and menus easier to follow in non-English games.

## What This Mod Adds

- Translation support for the 5Dim suite.
- Broad language coverage across many commonly used languages.
- A better experience for players who want 5Dim content localized in-game.

## Good Fit If You Want

- To play 5Dim in your preferred language.
- A more readable UI, item list and technology tree in non-English saves.
- Better accessibility for multiplayer groups using different languages.

## Requirements

- Requires 5dim_core.

## Notes

- Best used alongside the rest of the 5Dim modules.
- Translation coverage depends on the available language files for each release.

Part of the 5Dim mod collection for Factorio.
