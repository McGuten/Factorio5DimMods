# 5Dim's Mod - Core

Start every 5Dim setup on a clean, organized foundation.

5Dim Core is the required base for the whole suite, adding shared systems and cleaner item organization so every other 5Dim module fits together more smoothly.

## What This Mod Adds

- The required shared base for all 5Dim modules.
- Cleaner item groups and subgroups across logistics, production, combat, power and transport.
- A consistent tiered progression framework used by the rest of the suite.
- Support for modern 5Dim setups, including optional Space Age integration.

## Good Fit If You Want

- To use any other 5Dim module.
- A cleaner and more organized crafting interface.
- A modular way to expand Factorio without installing one giant overhaul.

## Requirements

- Required by all other 5Dim mods.
- Uses base Factorio.
- Space Age support is available when the DLC is installed.

## Notes

- Install this first if you are building a 5Dim mod list.
- Most player-facing content comes from companion modules such as Automation, Transport, Energy or Battlefield.

Part of the 5Dim mod collection for Factorio.
