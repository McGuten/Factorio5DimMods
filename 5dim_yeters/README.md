# 5Dim's Mod - Yeters

Adds Yeters, a post-edge endgame planet for Factorio: Space Age.

Yeters is unlocked after `promethium-science-pack` and connects from the solar system edge. The first implementation focuses on a playable planet, a new route, a Promethium-gated discovery technology and a harsh hybrid map with late Space Age resources.

Future passes can add Yeters-specific machinery, compact hybrid assembly lanes and alternate recipes that depend on local fluids instead of rewriting vanilla Space Age recipes.
