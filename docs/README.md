# Indice De Documentacion

Punto de entrada corto para la documentacion activa de 5Dim.

## Empieza Aqui

- [design-guide.md](design-guide.md): reglas generales de diseno y de lectura del repo.
- [design-modules.md](design-modules.md): resumen por modulo con bloques, rutas SA, categorias y excepciones canonicas.

## Diseno Transversal

- [design-planets.md](design-planets.md): mapa corto por superficie.
- [design-planets-detailed.md](design-planets-detailed.md): tiers concretos e items por superficie.
- [design-resources.md](design-resources.md): catalogo de recursos, afinidades y reglas de delta.
- [design-upgrades.md](design-upgrades.md): familias que se construyen como upgrade de otra base.
- [space-age-tier-art.md](space-age-tier-art.md): arte por tier de Space Age como capa base vanilla + overlay; decision, investigacion y alternativas descartadas.

## Validacion

- [validation-smoke-tests.md](validation-smoke-tests.md): perfiles, artefactos y uso del runner local.

## Planes

- [plans/](plans/): ideas y diseno futuro que aun no son fuente de verdad del comportamiento actual.

## Orden De Lectura Rapido

1. Lee [design-guide.md](design-guide.md).
2. Baja a [design-modules.md](design-modules.md) para ubicar el modulo o la familia.
3. Usa [design-planets.md](design-planets.md) o [design-planets-detailed.md](design-planets-detailed.md) si la duda es planetaria.
4. Usa [design-resources.md](design-resources.md) si la duda es de recursos o deltas.
5. Usa [design-upgrades.md](design-upgrades.md) si la familia reutiliza otra como base.
6. Usa [space-age-tier-art.md](space-age-tier-art.md) si la duda es sobre el arte por tier de Space Age.
